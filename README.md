# موقع الشركة

موقع ثابت (HTML + CSS + JavaScript) بالعربية والإنجليزية، بدون أدوات بناء. يُرفع على GitHub ويُنشر على Vercel مثل الموقع الشخصي.

## هيكل الملفات

```
index.html          الصفحة
styles.css          التصميم (الألوان، الخطوط، الوضع الليلي)
app.js              التشغيل (اللغتان، رسم النظام في الواجهة، نموذج الحجز)
data/content.js     كل النصوص والخدمات والأعمال والأسئلة وبيانات التواصل
assets/             الصور (أعمال سابقة، صورة المشاركة og.jpg) والعينات الصوتية assets/audio
favicon.svg ...     أيقونة الموقع
```

## تعديلات سريعة

- **اسم الشركة:** في أعلى `data/content.js` عدّل `brand.name` (عربي وإنجليزي). ثم عدّل `<title>` و`og:title` في `index.html`، وأعد صورة المشاركة `assets/og.jpg`.
- **التواصل:** في `data/content.js` داخل `contact`: رقم الواتساب `whatsapp` (بدون +)، والرقم كما يظهر `phoneDisplay` (مع ‎+966). البريد `email` لا يظهر في الموقع، ويُستخدم فقط إذا تعطّل إرسال النموذج.
- **سنة البداية:** `since` في أعلى `data/content.js`. يظهر أسفل الموقع «© 2025–السنة الحالية» وتتحدث السنة الحالية تلقائيًا.
- **استقبال طلبات الحجز على البريد (مهم):** ادخل web3forms.com واكتب بريدك، يصلك مفتاح (Access Key) على البريد. ضعه في `formKey` داخل `contact`. بعدها يضغط العميل "أرسل الطلب" فيصلك الطلب على بريدك مباشرة وتظهر له رسالة "وصلنا طلبك". إذا تركته فارغًا يفتح الزر تطبيق البريد عند العميل والرسالة جاهزة. واتساب يبقى خيارًا ثانويًا تحت الزر.
- **طريقة العمل (خارطة الرحلة):** في `data/content.js` داخل `phases` (الأطوار الثلاثة) و`journey` (المراحل الست). لكل مرحلة: `we` ما نفعله، `you` دور العميل، `get` ما يستلمه، و`gate` بوابة اعتماد بعدها (اختياري).
- **الحجز من التقويم:** ضع رابط Google Calendar (Appointment schedule) أو Cal.com في `bookingUrl`. عندها خيار «عن بعد» يفتح التقويم مباشرة (تأكيد ورابط Meet تلقائيًا)، وخيار «زيارة» يستخدم نموذج الطلب. إذا تركته فارغًا يستخدم الخياران النموذج.
- **أوقات الاجتماعات:** `slots` بنظام 24 ساعة. **أيام العمل:** `workDays` (0 الأحد إلى 4 الخميس). **عدد الأيام المعروضة:** `daysAhead`.
- **مشاريع قيد التطوير:** داخل `building` في `data/content.js`. المشروع الذي له صورة (`img`) يظهر كبطاقة كبيرة، والذي بدونها يظهر كبطاقة صغيرة. `status`: ‏`dev` = قيد التطوير، `future` = مشروع مستقبلي (تظهر تحت عنوان «مشاريع مستقبلية»).
- **رقم وثيقة العمل الحر أو السجل التجاري:** ضعه في `legal` داخل `contact`، فيظهر أسفل الموقع.
- **صورة المشاركة:** `assets/og.jpg` (1200×630). رابطها في `index.html` كامل (`https://sayr-company.vercel.app/...`)؛ غيّره عند ربط الدومين.
- **إضافة عمل سابق:** انسخ عنصرًا داخل `work` وعدّله، وضع صورته في `assets/work/` بعرض 1400 بكسل تقريبًا. لعمل بعينات صوتية بدل الصورة: ضع ملفات mp3 في `assets/audio/` واكتبها في `audio` (مثل مشروع `voice`).
- **رسوم الخدمات:** كل خدمة لها `visual` (‏`system` أو `dash` أو `agent` أو `flow`)، ونصوص الرسوم في `visuals`. هي أمثلة توضيحية وليست بيانات عملاء.
- **إضافة خدمة أو سؤال:** داخل `services` أو `faq` بنفس الطريقة.

## النشر على Vercel

1. أنشئ مستودعًا جديدًا على GitHub، مثل `company-site`، وارفع كل الملفات كما هي (المجلدات مع الملفات).
2. في Vercel: Add New ← Project ← اختر المستودع.
3. Application Preset: **Other**، واترك إعدادات البناء فارغة، ثم Deploy.
4. لربط الدومين: Settings ← Domains ← أضف الدومين واتبع تعليمات DNS.
5. بعد ربط الدومين، عدّل `og:image` في `index.html` إلى رابط كامل، مثل `https://الدومين/assets/og.jpg`.

## النسخة الإنجليزية

أضف `?lang=en` لنهاية الرابط، أو اضغط زر English في أعلى الصفحة.
